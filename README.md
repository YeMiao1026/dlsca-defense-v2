# dlsca-defense-v2

用**成本匹配**的方式系統性、誠實地再評估對抗式擾動類SCA防禦（learned generator／universal perturbation／高斯噪訊）——不是預設GAN會贏，是把各種手法放在同一套嚴謹評估（100-run GE、TVLA、SNR）下公平比較，包括誠實報告負面結果。是「基於生成對抗網路之主動式對抗旁通道防禦機制」專題的防禦端子系統，攻擊端另案 [`dlsca-attack-v2`](https://github.com/YeMiao1026/dlsca-attack-v2)。方向依據 B11209017/方向.md 的Route A建議修正，見 `CLAUDE.md` §1/§8。

完整計畫、威脅模型、跟攻擊端的介面定義見 [`CLAUDE.md`](./CLAUDE.md)。

> **⚠ 重大方向修正（見 `CLAUDE.md` 附錄F）**：先前版本的README/報告把「D01比高斯噪訊效率差」當成核心結論，這個比較方向從一開始就搞反了——GE越低才是攻擊越成功，D01（GE@9000=111.84, N_TGE=None）在9000條軌跡內**從未被攻破**，成本只要高斯達到同等效果所需門檻（PSR=0.1337）的**約1/5**。TVLA跟D06（自適應攻擊者）兩個獨立、不受這個方向影響的檢查完全不受影響，而且合起來把故事講得更有力：D01單看GE甚至像是「贏了高斯5倍效率」，但TVLA顯示底層洩漏幾乎沒動，D06顯示攻擊者一旦重新訓練就幾乎完全打回原形——**GE贏是假象，而且贏得很誇張**。

**補測D02/D03其餘6個變體後，三層對照完整了**：D02全部4個變體TVLA幾乎不變（GE雖高達197.76也是假象，跟D01同一套失敗模式）；D03呈現真實的劑量反應（noise_std越大TVLA改善越明顯），其中D03_high（純隨機性，沒有D04的loss設計）的自適應攻擊者測試GE曲線明顯下滑（N=1000時83.63→N=9000時17.99，正在被攻破中），跟D04的完全平坦（124-138無趨勢）形成清楚對比——**D01（無真實效果，秒破）＜D03_high（部分真實效果，撐比較久但正在瓦解）＜D04（最多真實效果，目前未見瓦解跡象）**，效果強度跟抵抗力呈現一致順序，證實D04的loss重新設計有實質貢獻，不只是「加隨機性」這麼簡單。

## 跟攻擊端的關係

不共用程式碼，只共用資料格式：防禦端輸出一個 `defended_traces.npy`（跟攻擊端 `attack_traces[split.e]` 同shape），呼叫攻擊端既有的 Stage B 評估介面（`02_run_attack.py --traces/--out` + `03_evaluate.py --probs/--out`）拿到嚴謹的 100-run GE/N_TGE 結果，不自己另外寫評估邏輯。細節見 CLAUDE.md §2。

## 環境需求

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

需要能存取一份已經訓練好的 `dlsca-attack-v2` 攻擊者（`runs/{exp}/model.keras` + `config_snapshot.yaml` + `split_indices.npz`）跟同一份 ASCAD 資料。
